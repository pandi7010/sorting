ESP32 & 74HC595 Shift Register Connection Guide

This guide provides instructions on how to connect an ESP32 micro-controller to a 74HC595 Shift Register IC using an External 5V Power Supply.

⚠️ IMPORTANT (மிக முக்கியம்): You MUST connect the Ground (GND) of the external 5V power supply to the Ground (GND) of the ESP32. Without this common ground, the data signals will not work.
ℹ️ Note on Logic Levels: The ESP32 outputs 3.3V logic, while a 5V-powered 74HC595 expects 5V logic. Direct connection usually works, but for maximum reliability in long-term projects, using a 74HCT595 or a logic level shifter is recommended.

English Connection Guide

From To (74HC595 Pin) Purpose
External 5V (+) Pin 16 (VCC) Main Power for IC
External 5V (-) GND Pin 8 (GND) Ground for IC
External 5V (-) GND ESP32 GND Common Ground (Crucial)
ESP32 GPIO 23 Pin 14 (SER) Serial Data Input
ESP32 GPIO 18 Pin 11 (SRCLK) Shift Register Clock
ESP32 GPIO 19 Pin 12 (RCLK) Storage Register Clock (Latch)
GND Pin 13 (OE) Output Enable (Active Low)
External 5V (+) Pin 10 (SRCLR) Clear (Active Low, connect to HIGH to disable)
